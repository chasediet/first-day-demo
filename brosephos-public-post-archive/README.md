# Brosephos Public Post Archive

Archive of publicly accessible posts and replies attributed to the X/Twitter account @Brosephos.

## Purpose

Preserve source information for publicly accessible posts that contain derogatory or personally insulting remarks.

## Evidence standard

Each archived item should record:

- Exact quoted text
- Original X/Twitter status URL when recoverable
- Archive or mirror URL
- Post date/time when recoverable
- Capture date
- Screenshot or preserved image when available
- Context needed to avoid misleading quotation
- Verification status

Screenshots of actual webpages must be distinguished from recreated transcription/reference images.

## Structure

- `screenshots/` — individual evidence images
- `records/` — one source record per post
- `index.md` — running catalog of verified items

## Limitations

This archive covers publicly recoverable material only. Deleted, protected, or never-indexed posts may be unavailable.
